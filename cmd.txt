StartupAI run commands

Start all local AI services
powershell -ExecutionPolicy Bypass -File .\start-all-servers.ps1

Single-service launcher examples
powershell -ExecutionPolicy Bypass -File .\start-server.ps1 rag
powershell -ExecutionPolicy Bypass -File .\start-server.ps1 predictor

Frontend
npm run dev
